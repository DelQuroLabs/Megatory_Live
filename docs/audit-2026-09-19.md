## Findings (do not treat as passes)

### P1 — security / honesty

| ID | Finding |
|---|---|
| F-SEC-MQTT | Hospital notebook is ciphertext on **public** MQTT brokers (`broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`). User asked for **own-server** storage. A 4-digit PIN + topic `hospital-pinDigest20` is brute-forceable if someone knows the hospital code. |
| F-SEC-PIN-STORAGE | Site PIN sits in AsyncStorage as JSON, not Keychain. Shared iPad = recoverable PIN. |
| F-SEC-ADVISORIES | `npm audit`: 27 issues (15 moderate / 11 high / 1 critical), Expo toolchain. Untouched. |
| F-SEC-PAGES-HTTP | GitHub Pages `https_enforced: false`. Human must tick HTTPS-only. `html_url` still reports `http://megatory-live.delqurolabs.app/`. |
| F-CHARTER-DRIFT | Charter/intake still said local-only until this audit. Product is hybrid-sync + kiosk. Records updated to match **current** code, and to name the own-server gap. |
