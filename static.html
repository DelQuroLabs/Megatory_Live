Where is scanning in native app?

Full scanning lives in app/scan.tsx:

import { CameraView } from 'expo-camera'
<CameraView
  barcodeScannerSettings={{
    barcodeTypes: ['ean13','ean8','upc_a','upc_e','code128','code39','qr']
  }}
  onBarcodeScanned={handleBarcode}
/>
// handleBarcode: lookup local inventory by barcode
// if found → prompt Add Quantity (adds to count)
// if not found → navigate to /add?barcode=...

Expo Go app: npx expo start --clear → scan QR → camera permission → scan bottles. Works offline, no network needed. Manual entry fallback for things it can't find (compounded, no barcode).
